# Ordo_Fractum
**Ordo Fractum** is a 3D, third-person video game set in medieval Europe with a focus on precise input timing, resource management, and challenging melee combat.

## Key Features
* **Tactical Melee Combat:** A deflection system built on timing, counterattacking, and tactical decisions.
* **Resource Management:** Balance your will, fortitude, and items to survive difficult encounters.

## Technical Details
* **Engine:** Unity 6.4 (6000.4.6f1)
* **Language:** C#
* **Version Control:** Git / GitHub Desktop
* **Platform:** PC / Windows
